\# DevSecOps Pipeline Project (Express.js)



\## 1. Nama Aplikasi \& Fungsinya

\- \*\*Nama Aplikasi\*\*: DevSecOps Simple REST API

\- \*\*Fungsi\*\*: Aplikasi backend sederhana berbasis Node.js untuk menguji integrasi pipeline keamanan perangkat lunak (DevSecOps), yang menyediakan endpoint data dummy, echo data, serta dilengkapi dengan pengujian unit otomatis.



\## 2. Bahasa/Framework yang Digunakan

\- \*\*Bahasa Pemrograman\*\*: JavaScript (Node.js)

\- \*\*Framework\*\*: Express.js

\- \*\*Testing Framework\*\*: Node.js built-in test runner (`node:test`)

\- \*\*Security Scanner (SAST)\*\*: Semgrep
